# Icon Normalizer v1.1.10

发布日期：2026-11-06。扩展 **1.1.10**、配套后台 **3.1.8**，支持范围为已测试的 **GNOME Shell 51**。API 版本仍为 1，渲染核心版本仍为 2。

## 本次修复

- **规则跨目录跟随**：应用更新图标时，常把同一张图重新导出到另一个尺寸目录。此时规则键（进程内用 SHA-256、手工配置可能是路径）会失配，图标悄悄退回自动分类。
- 现在规则查找有三层：协议 SHA 键 → 原始图标字符串 → **唯一文件名回退**（借助上一轮清单记录的源路径还原文件名）。
- 歧义安全：同名规则多于一条时不匹配，避免把 A 应用的规则套到 B 应用。

## 可观测性

- 每条运行记录新增 `rule_matched_by`：`exact`（原样命中）、`basename`（经文件名接续）、`none`（无规则）。

## 验证

- 全量测试 **237 项通过**（新增 `test_rule_rebind.py` 7 项）。
- 端到端覆盖：PWA 式绝对路径图标从 `256x256` 迁移到 `512x512`，规则仍以 `glyph` 渲染且 `rule_matched_by = basename`。
