# Icon Normalizer v1.2.0

发布日期：2026-11-06。扩展 **1.2.0**、配套后台 **3.1.20**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

> 这是自 **1.1.8** 以来第一个面向用户的发布。中间的 `1.1.9`–`1.1.51` 是开发过程中的版本号，从未公开发布，也没有单独的用户意义 —— 详见 [RELEASING.md](RELEASING.md)。

## 一句话

图标规则从「设好之后就不能碰」变成「会告诉你它失效了、并能一键修好」。

## 新增

### 1. 规则失效不再静默

以前：应用换了图标 → 规则悄悄失效 → 图标退回自动分类，没有任何提示（DeepSeek Harness 就是这样变成尖角白方块的）。

现在：

- 维护页顶部提示「检测到 N 条图标规则已失效」，点「查看详情」可逐条看到应用名、错误码与当前指纹；
- 顶栏指示器（开启时）发一次桌面通知，可在「维护 → 规则失效时通知我」关闭，同一问题不重复提醒；
- `status` 输出新增 `rules_health`（按状态计数）与 `rule_warnings`。

### 2. 规则可以就地修

- **规则页**新增「逐图标规则」分组：每行一个类别下拉框 + 「重置」按钮；
- **应用页**新增「有规则」筛选，副标题标出分类来源（用户规则 / 已复核）；
- **详情弹窗**提供「重置为自动」；重置时会同时清掉本机遗留的同名覆盖规则。

### 3. 应用更新后规则能自己接续

应用把同一张图重新导出到另一个尺寸目录时，按**唯一文件名**自动匹配，无需手动重设（候选不唯一时拒绝猜测）。

### 4. 新增圆角底板类别 `plate-rounded`

保留源图图案、把直角轮廓换成 squircle。扫描时若检测到「四角不透明的满幅直角底板」，会给出 `suggested_class` 建议，预览弹窗可一键切换。

### 5. 其他

- **自备图标不被覆盖**：`keep_desktop_override` 让用户自己的 `.desktop` 图标保持原样；
- **孤儿图标清理**：插件自有主题里没被引用的 PNG 每轮清理，删除纳入事务；
- **健康事件闭环**：规则失效记 `degraded`，恢复后补记 `recovered`。

## 新增设置项

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `notify-rule-warnings` | 布尔 | `true` | 规则失效时是否发送桌面通知 |
| `notified-rule-warnings` | 整数 | `0` | 上次已提醒的告警数（去重用，重启 Shell 不重复提醒） |

## 升级说明

- 新增的两个设置键都有默认值，旧配置无需迁移。
- 已有规则继续有效；因应用更新而失效的规则会出现在维护页的告警里。
