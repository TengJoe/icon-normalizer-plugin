# Icon Normalizer v1.1.27

发布日期：2026-11-06。扩展 **1.1.27**、配套后台 **3.1.19**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 背景

对真实产物做全量审计（634 个 PNG / 74 个图标 × 9 尺寸）时发现 9 个孤儿文件：`local.deb.Installer.png` 的九个尺寸仍是**旧策略 88%** 的产物，且没有任何清单条目再引用它们。此前插件只清理自己记录过的文件，应用改名或策略变化后旧图会一直留着。

## 修复

- 每轮运行删除主题 `*/apps/` 下未被任何条目引用的 PNG（该目录由插件创建并拥有）。
- 删除同样纳入事务：失败时随其它改动一起回滚。

## 验证

- 后端全量 **253 项测试通过**（新增 `test_orphan_cleanup.py`）。
