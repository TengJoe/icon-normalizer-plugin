# Icon Normalizer v1.1.20

发布日期：2026-11-06。扩展 **1.1.20**、配套后台 **3.1.16**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **规则失效通知**：顶栏指示器发现规则不再匹配源图时，发送一次桌面通知，附带数量与「可在设置中查看并重置」的指引。
- **去重**：同一告警数只提醒一次；数量变化或修复后复发会重新提醒。
