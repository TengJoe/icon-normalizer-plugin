# Icon Normalizer v1.1.23

发布日期：2026-11-06。扩展 **1.1.23**、配套后台 **3.1.18**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **圆角建议**：扫描时若发现图标是"满幅直角底板"（四角不透明），`scan` 结果会带 `suggested_class: "plate-rounded"`。
- 预览弹窗据此显示「建议改为圆角底板」提示与「改为圆角」按钮，点击即写入规则并刷新预览。

## 背景

`plate-rounded` 在 1.1.11 加入，但一直只能靠手写规则启用；`suggest_class()` 从未被调用。本版本把建议接到扫描与预览，用户可以在界面上发现并修复这类图标。

## 验证

- 后端 **252 项测试通过**（新增扫描建议用例）；前端 **5 组全绿**；`npm run lint` 无告警。
