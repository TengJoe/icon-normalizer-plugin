# Icon Normalizer v1.1.16

发布日期：2026-11-06。扩展 **1.1.16**、配套后台 **3.1.14**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **维护页「上次运行处理」**：一行展示上一轮的动作分布（放大 6 · 缩小 59 · 补底板 4 · 保持 14 …）与文件改动数，便于快速判断插件到底做了什么。
- **`status.rules_health`**：返回 `states`（`active` / `stale_source` / `unbound` / `invalid` / `none` 计数）与 `warnings`（上次运行的失效告警数），可直接用于监控。

## 兼容性

- `rules_health` 为**可选**字段，已登记到发布契约；旧客户端不受影响，缺失时为 `null`。

## 验证

- 后端 **249 项测试通过**（新增 1 项）；前端逻辑 **16/16 + 11/11 + 13/13 ×2 + 5/5** 全绿；`npm run lint` 无告警。
