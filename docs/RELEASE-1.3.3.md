# Icon Normalizer v1.3.3

发布日期：2026-11-08。扩展 **1.3.3**、配套后台 **3.1.20**（未变更），支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

单缺陷修复版：来自运行中的真机报告（规则页截图）。

## 修复

**规则页「自定义方案」误报"此功能需要后台 3.1.0 或更新版本"。**

- 根因：界面能力门 `supportsProfilesAndThemes` / `supportsSafeSkip` 用 `^\d+\.\d+\.\d+$` 解析 `status.backend_version`，而纯 GJS 后端返回 `gjs-1`——解析失败即判"后端过旧"，于是**已被纯 GJS 后端完整实现的命名方案与安全跳过在界面上被禁用**。这与 1.3.2 修复的五个缺陷同类：实现没错、协议没错，是界面按旧伴生的版本号绘制状态。
- 修复：`gjs-*` 一律视为完整能力（这两个门当初只用于区分旧 Python 伴生的 3.0.x / 3.1.x）；旧 Python 版本号的判定逻辑不变。
- 测试：Q20 契约新增断言——真实 `status` 载荷必须通过界面绘制的全部能力门；Q4 逻辑测试新增 `gjs-1` 用例。

## 验收

- **20 道质量门**全量通过（`bash tools/verify.sh`），含 Q18 69 项 GJS 单测 + 9 项 UI 载荷契约用例、Q19 parity、Q20 覆盖率检查。
- 真机验证：规则页方案区不再出现误报警告，保存为自定义方案可用。
