# Icon Normalizer v1.1.25

发布日期：2026-11-06。扩展 **1.1.25**、配套后台 **3.1.18**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 改进

- 规则失效通知的去重状态持久化到 GSettings（`notified-rule-warnings`），Shell 重启后不再重复提醒同一个问题。
- 告警数量变化、或修复后再次出现时，仍会重新提醒。

## 兼容性

- 新增 GSettings 键（默认 0）；旧配置无需迁移。

## 验证

- 前端套件 **5 组全绿**（指示器 15/15，含"已写入设置"断言）；`npm run lint` 无告警。
