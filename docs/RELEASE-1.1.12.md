# Icon Normalizer v1.1.12

发布日期：2026-11-06。扩展 **1.1.12**、配套后台 **3.1.10**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **`keep_desktop_override`**：与 `skip` 一起使用时，插件释放该图标的启动器记录，但保持启动器文件原样（不还原、不删除）。适合"我自己提供图标，插件不要管"的场景。

```json
{ "skip": true, "keep_desktop_override": true }
```

## 修复

- `rules.set` 的分类白名单补上 `plate-rounded`（1.1.11 引入该类别时遗漏，导致只能手工改配置）。
- 修正 `skip` 判定误把带 `classification` 的规则当成纯跳过开关的问题。

## 兼容性

- 默认跳过行为不变：生成的启动器会被还原或删除，系统条目重新接管。
- 存储格式向前兼容，旧规则无需迁移。

## 验证

- 全量测试 **245 项通过**（新增 2 项跳过语义测试 + 1 项协议回归测试）。
