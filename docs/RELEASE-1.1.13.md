# Icon Normalizer v1.1.13

发布日期：2026-11-06。扩展 **1.1.13**、配套后台 **3.1.11**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **维护页规则告警**：当上次运行存在失效规则时，维护页顶部显示常驻提示，例如"检测到 1 条图标规则已失效：源图或分类发生变化，相关图标已退回自动分类。"
- 告警数据来自 `last-run.json` 的 `summary.rule_warnings`，因此无需额外请求；后台状态读取失败时提示自动隐藏，避免误导。

## 背景

1.1.9 起后台已能报告规则失效（`rule_state` / `rule_warnings` / 健康事件），但用户只能查看运行记录文件。本次把它接到设置界面，规则失效真正"看得见"。

## 验证

- 前端逻辑测试 **15/15 通过**（维护页 10 项，含新增 2 项）；i18n 覆盖 **5/5**（254 条英文文案）。
- `npm run lint` 无告警。
- 端到端实测：临时把 DeepSeek 规则的指纹改坏 → 运行记录 `summary.rule_warnings = 1` 且明细含 `RULE_STALE_SOURCE`；还原后归零。
