# Icon Normalizer v1.1.22

发布日期：2026-11-06。扩展 **1.1.22**、配套后台 **3.1.17**，支持范围为已测试的 **GNOME Shell 51**。API 版本 1，渲染核心版本 3。

## 新增

- **「规则失效时通知我」开关**（设置 → 自动维护与显示）：默认开启；关闭后不再发送规则失效的桌面通知，维护页告警仍然保留。
- 设置键：`notify-rule-warnings`（boolean，默认 `true`）。

## 兼容性

- 新增 GSettings 键，旧配置无需迁移（缺省即开启）。
- 指示器读取设置失败时回退为"开启"，保证不会静默丢通知。

## 验证

- 前端套件 **5 组全绿**（指示器 15/15，新增 2 项通知开关测试）；`npm run lint` 无告警。
